# 住宅电施审核稿复核

照明平面按[照明布点前的建筑依据与跨层复核](<../../references/lighting-survey.md>)准备 input/lighting_survey.json，预检及保存后集中回读共用。修订发现共用逻辑错误时，按楼层清点同类空间并记录结果。

## 整套审核稿提速

按连续墙钟时间给常规新项目分配预算。资料与原生底图识别 4–5 分钟；共用楼层、房间和实墙数据，组装平面、系统及样板页 12–16 分钟；任务包预检、后台首次成图及原生回读 2–4 分钟；集中图面复核、修订与交付 7–10 分钟。合计 25–35 分钟。计时从开始处理输入起，等待和重试计入总历时。第 25 分钟记录是否已取得首轮 DWG；若预计超时，记录实际阻塞步骤并继续处理。

准备阶段按当前项目确认弱电应出楼层，独立于已生成的目录。校准数据由 `review_preflight.py sockets` 按本项目样板取得。组装插座原生块时，可直接使用同模块的 `socket_copy_parameters(symbol, world, normal)` 产生来源、原件、安装边、落点和角度。新建整套采用下列入口提交，脚本核对实际入池的 `input/build.json` 及样板文件，合并报告插块方向、安装边、缺页与同墙面板冲突。现有池仍由原调度器运行。非此格式的原生生成器应映射等效的实际变换，保存 DWG 的局部修订使用原修订入口。

```powershell
& ./work/electrical-plot-batch/submit_review.ps1 -Package $projectPackage -Name $jobName -WeakFloors $requiredWeakFloors -MountWidths $measuredWidths
```

样板更换时将重新实测的哈希和原件参数通过 `-Calibration` 传入。定稿的 A3 满幅 1:100 视口共用 `review_plots.py <任务output目录> <项目work目录> --build <实际build.json>` 提取黑白、彩色总览和全部设备局部。点位、回路、图面及待核项在同一个保存版本集中核对；有问题按影响页修正，最终整套试打并核验。仅局部回放的计时单独列明。

出图前按原图建立项目清单。旧项目的句柄、坐标、图幅数量及朝向不得带入新项目。修订时可在来源 DWG 哈希一致的前提下复用清单，增页、换块或调整入户位置时同步更新。未清理底图不得进入各专业平面复用。

1. **底图**。逐边识别尺寸测量对象：总宽/总深和轴间主要定位尺寸保留，门窗分段和内部细部尺寸清理。轴线、轴号、建筑墙柱及保留尺寸的必要界线均保留。进入轴网等嵌套块检查独立线、闭合折线、辅助框和原生标注。辅助层可能混有其他几何，须先辨认，不能整层删除。生成后用源至目标的克隆映射建立最终句柄清单，核查每个实际使用的底图块。模型空间还须查看不参与打印的辅助线。
2. **首层市政进线**。从建筑墙面、箱体实际轮廓和批准的穿墙位置确定室外箭头，并标注“接电力局市政电源”。沿审核03的表达，动力线用样板动力图层及统一线宽接总箱，保护联结单独从 MEB 接总箱保护母排。图例或插入点不能代替箱体真实接线边；总箱平面端点需与配电系统图对照。本项目确认的是 MEB 附近进户，其他项目按各自穿墙点定。
3. **图例避让**。逐张保留样板完整图例的字体、表格、符号和实尺，用整表范围选择图框内空白位置。插入前和保存后均核对轴号圈、尺寸、图名和标题栏。其他专业平面图的散排图例也按组核对。预筛可取底图、轴网整体包围框；出现相交则整体移位，或提取实际障碍轮廓并核对局部试打。粗包围框相交只表示待核。不得以缩小图例或关闭轴号解决。

## 运行方式

图签按建筑图框的实际格线定位。生成前先清点块内文字、块属性及块外散字，每项选定唯一写入对象；移除图号格内旧专业前缀、编号后缀或重复文字。缺比例栏时，在图签空白处按原样式补设“比例”标签和值格，填写本页比例。保留日期和值、设计号、版次等栏位。交付前逐页回读并查看图签局部试打；查出叠字、越格、错误栏位或缺少栏位依据时，修正并复核使用同一图框的所有页。

### 进户方向与卫生间门口

- 首层进线复核时，在同一张原生回读图上从 AM 箱边追到室外箭头。对照本项目进户方向和穿墙位置，核定起点是否在朝外的正确箱边；回读有折点时逐处指出迫使直线避让的箱体、柱或标注。端点连通、线宽正确也要核对这一项。
- 卫生间逐间关联灯组、实际通向干区的门洞和开关。回读时对照该门的开启弧、把手侧门垛和实际干区安装面；首选处受挡时在同一门口复选。对套卫须分别辨认卧室入口、套卫入口。仅当项目明确采用入口集中分控时按逐键关系核对。
- 这两项复用整套审核稿已有的门洞数据、DWG 回读和局部试打。记录实际出线边及折线避让对象、卫生间开关对应的门与墙面；脚本的端点或贴墙检查只覆盖其各自的几何判项。

在工作区运行：

```
python work/electrical-plot-batch/verify_electrical_review.py <最终DWG原生回读.json> <设计清单.json> <本项目复核依据.json>
```

三个输入必须来自当前项目和相应版本。原生回读需带模型空间、块表、实体句柄、图层、包围框和多段线的顶点与统一宽度。设计清单使用生成器的 sheets。复核依据的字段如下。

- backgroundLayers 指定承载各层底图引用的实际图层。backgrounds 逐一列出底图块名 base、应移除的最终句柄 remove、应保留的句柄及原生类型 retain、应保留的天正尺寸实体数 nativeDimensionCount。对无目标图元的底图也记录保留依据。
- titleFields 以每张图号为键。area 是包含完整图签标签、数值的区域；number、scale、date 为按本图格线量取的三个独立值格（不含栏名）。各框按相对本页左下角的模型坐标填写四个数 xmin、ymin、xmax、ymax。dateValue 为本页预期日期，scaleValue 默认为 1:100。可复用同款图框的实测分格。检查展开块内文字和块属性，并同时遍历块外叠字。对于非零块基点，原生回读须提供 blockOrigins 或先换算至统一坐标；无法解析的代理文字、非矩形单元格或仅有保守包围框的文字须结合原生几何及局部试打复核。
- services 按进线列出 am、meb、feed、arrow、bond、caption 的最终模型空间句柄。outsideTip 用独立确定的室外目标点，tipIndex 是箭头尖顶点的序号。powerLayer、bondLayer、width 从所用样板量取。脚本支持样板的直线段多段线、折线箭头及轴向矩形箱体；其他表达需从原生几何核对等价导通与避让，记录结果。
- legends 按插座图号完整列出该页整表或组成图例的全部句柄 legend，以及实际需避让对象的模型空间句柄 protected。嵌套轴号没有独立模型空间句柄时可先选外层底图块作保守筛查。散排图例页、细化的旋转轮廓及标题栏可另用原生局部几何和试打交叉核对。空白区还须位于图框有效绘图区内。
- 输出分别列出底图、进线、图例问题。非零退出码须排查。逐页对照图上可见几何、各楼层应出图清单和最终打印，才能记为验收通过。历史对照依据仅供看字段结构，见邹府审核03工作目录中的“三项复核依据.json”。
