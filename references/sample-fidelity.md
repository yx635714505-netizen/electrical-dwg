# 样板复用与交付验收 V08

适用于住宅电气新出图及既有 DWG 修订。表达样板以用户指定的电气 DWG 和截图为准。项目尺寸、楼层、房间、回路、基础和设备资料以本项目为准。

## TV、TD 客厅弱电平面 V23

布点范围、贴墙线路和交付计数执行 [V23 客厅弱电平面](panels-service-and-weak-plan.md)。电视墙缺少标注时结合电视柜与沙发朝向选择可用实墙，并注明推定依据。

## 样板与底图校核

1. **目录、说明和系统图。** 执行 [目录说明与系统图 V09](front-sheet-template.md)。目录和说明整页继承，系统图一按项目回路复用完整样板单元，系统图二独立保留通用示意。
2. **门窗底图（V11）。** 在电气底图专属副本中，先保全门窗洞口及关联墙轮廓，再移除带随件编号的天正门窗原件。保留窗框线、门扇、开启弧和洞口，最终有效色为 ACI 8。用 [后台清理程序](../scripts/CleanElectricalBackground.cs) 递归处理普通文字、天正文字和块属性中的门窗编号。关闭图层或设为不打印仍可能在天正模型里显示随件编号。保存后用默认交付检查核对块内容，并通过彩色图逐层核对洞口和开启弧。
3. **通讯布线。** 按 V23 从对应 ADD 到客厅电视点组画一条连续贴墙线路。按V32使用青色 ACI 4、实体随层、1:100多段线宽35及样板TG_WF。核对ADD完整箱体背边贴墙及客厅线路端点。参考样板的 `WIRE-通讯` 可为 Continuous 层默认，实体另指定复杂线型；按样板核对有效线型、字样、线宽与比例。
4. **防雷接地表达。** 屋面外围、原生标高及完整说明执行[V34](roof-lightning-v34.md)。 复用完整原生图例和说明段落，项目字段尽量原位修改，不用普通文字替换天正文字。明敷接闪带 `TG_×`、暗敷网格 Continuous、接地 `TG_E`。把复杂线型定义、字体或形文件依赖一起迁移，比较同名定义及节距，避免克隆时同名资源被抢占。最终同时检查彩色模型和出图效果，平面与表格的符号、颜色、材料、安装高度一致。
5. **基础接地网。** 首层梁图清理后淡显，用于轴网和柱位定位。另从实际基础图核对条基、基础梁和柱脚。明确纳入接地网的基础梁或沿基础敷设的导体段，逐段沿梁定位绘制，在交叉和转接处保持连通。独立基础间无连续基础梁时，按明确的埋地连接方案处理。外围补充接地体由项目条件确定。核对内网、跨区连接、引下线编号、测试点及 MEB 的可追溯连接。顶梁不等同于埋地接地体。

防雷接地样板来源见 [样板清单](sample-manifest.json)。通讯图采用 WF 表达时，核对 `TG_WF` 定义和 `WF` 字形，样板平面线宽为 35 模型单位。保持样板实际节距，分别检查全局比例、实体比例、模型注释比例及布局比例。防雷图例中天正版本无法安全原位改写 `TCH_TEXT` 的项目字段，可沿用该对象原生展开得到的显示文字，继承其位置、样式和高度，并保留其余原生表格内容。

出图前记录样板来源、基础图来源和拟参与接地的段。交付前把五项分别核验到实际 DWG。目录和图框字段与实际布局一致，系统回路与项目回路表一致，开口展开几何及编号通过检查，弱电实体有效颜色和路由符合样板，防雷接地导体连通且复杂线型在图面可见。原生回读、文件大小和图纸数量只说明文件结构，图面和项目条件必须另核。修订现有 DWG 时同时检查轴网、天正图名、设备贴墙、照明直连和插座取消项。

## 建筑固定装饰柱保全 V33

建筑平面中的固定装饰柱是电气底图需保留的建筑构件。逐层识别柱体、柱脚、柱帽、包柱、相接线脚以及构成其完整形体的线段、填充和嵌套对象，按原位置与尺寸保留，并按建筑底图淡显。露台、阳台、门廊及建筑转角的柱位一并检查。

保留判断以建筑构件的实际几何、位置、功能及关联关系为依据。图层白名单应覆盖已识别构件及其关联对象；使用“立面看线”“立面线脚”“装饰”“杂项”等图层的平面柱轮廓也须检查。同类柱可由原生柱、柱组嵌套块或普通闭合多段线表示，识别范围须覆盖这些形式，不能只提取 TCH_COLUMN。构件跨出主体墙线或局部选区时按完整轮廓确定提取范围。复用旧底图筛选器前，检查其固定保留图层、实体类型筛选和裁切范围是否遗漏这些构件。

天正原生柱对象与最终可见柱形分别核对。需要修复显示时，保留原生柱对象，依据源图恢复缺失的原生关联线脚或柱体显示几何，记录源构件及其回读对应。修改共享底图块后核对所有引用该块的照明、插座、弱电等平面；涉及其他楼层时按该层原图提取各自构件。

交付检查列出原建筑图的柱位、几何范围、关联轮廓和原生对象，逐柱对照底图处理前后及最终DWG。分别检查对象存在、有效颜色与图层显示、实际尺寸和试打中的柱体连续性。对有无柱脚、柱帽及关联线脚逐项确认，整套平面检查完成后出图。
