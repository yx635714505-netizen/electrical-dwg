# 后台原生CAD

本用户环境：AutoCAD 2020 + 天正TArch20V8，.NET Framework 4。用原生Database/WblockCloneObjects复制天正实体、图层、文字样式及线型，不转T3，不以DXF重建全部图纸。原图只读，工作副本另存版本。

本机统一使用 `./cad_pool/pool.ps1`（用法见同目录 `使用说明.md`），最多5个CAD工作进程，运行与排队等未结束任务合计最多5个。每次运行创建独立隐藏Windows desktop、acad.exe、Profile和任务目录；不要GetActiveObject连接用户CAD，也不要打开桌面可见窗口或要求用户反复按Esc。旧 `hidden_desktop.cs` 的固定desktop和历史公共通道不再作为并发启动入口。只有核对归属后才停止该任务进程。

.NET引用：`C:/Program Files/Autodesk/AutoCAD 2020/{acdbmgd,acmgd,accoremgd}.dll`。编译器`C:/Windows/Microsoft.NET/Framework64/v4.0.30319/csc.exe`。需要Tianzheng原生运行时加载后读取对象。

脆弱点：整个处理过程FILEDIA=0；所有NETLOAD先完成，不能中途设1而触发隐藏文件对话框。并发任务Lisp和插件放本任务 `scripts/`（调度器为所属Profile配置受信路径），禁止再向公共天正sys目录写固定名称临时脚本。脚本完整表达式且末尾换行。根目录从 `CAD_POOL_JOB` 环境变量获取。先保存检查点再修改原生标题，修改后重新读entget并核对几何中心；未知属性不能猜测写入。

通过原生Wblock复制assets中的实体及其依赖。样板文字样式同名但定义不同时须核对实际字体，不可仅按名字Ignore覆盖冲突。块TransformBy已变换附属属性，不再重复变换属性坐标。淡显仅作用于底图及其专属依赖，不递归改坏共享电气符号或图框。

本地历史出图脚本含项目句柄、旧图名3.5/2.45、三列排图及TG_LP等过期实现，不能直接运行。历史验证`D:/水电SKILL/output/清水村申府_电气_V03/work/validate_revision.py`可作轴网、箱体、取消项的实现参考，句柄和工程数据需重新生成；新的图名/排图检查以本技能为准。

发生接口忙碌时，查当前任务脚本状态及日志，修正完整命令后在工作副本重试；失败检查点不当成最终交付。最终采用独立Database.ReadDwgFile读回保存文件，不能只用当前内存数据库充当回读验证。


## 默认出图顺序与局部重试

在本技能工作区内采用共享 build.json 的住宅新建任务使用 [整套审核稿提速入口](<../work/electrical-plot-batch/三项复核.md>)。submit_review.ps1 在入池前用本次样板核对实际插块指令、弱电楼层及面板净距，定稿按同版原生回读及试打集中核对。以收到资料至交付的连续历时衡量 25–35 分钟目标。

1. **准备与绘制合并。** 同一项目的建筑、结构各读取一次。按本次源文件版本、坐标系和楼层保存识别结果，照明、插座、弱电共用。按样板文件内容版本、原生符号、单位及提取方法复用已验证的安装边、接线点和朝向；旋转和镜像仍按当前实例变换。未校准的符号先在工作副本集中核对，再整批插入。项目房间、墙面、安装点和回路随当前项目重新确定。
2. **改稿只处理受影响的内容。** 将同轮问题合并修改，优先从最近已成功保存的工作副本继续。移插座而用途、数量、支路均相同，中间只试打该插座页，并核对相邻面板；动了配电箱则带上使用同一箱的所有平面、相关线路及受影响的系统页。修改共用块、底图或打印设置时展开所有引用页；影响范围不明则检查全套。局部图面查看优先从同版整页 PDF 放大或裁切，打印比例仍用原图。需要核对特定颜色、线宽或局部精度时补对应试打。修订轮按问题选择黑白或彩色，只在两者都相关时各出一份。
3. **定稿集中验收。** 一次另存至新版本并关闭写句柄，再独立打开所存文件。把原生实体、块与属性、布局、图层和端点一次导出供各项检查共享；缺少的对象信息定向补读。定位、符号、回路、版式及禁止项各执行一次，汇成一份问题清单。在同一份最终 A3 试打中检查整页和逐点局部，页码/区域可同时作为多个检查结果的依据。若该版本一次通过即交付；修订后重新对最终版本做回读和全套出图。遇保存、打印或导出失败，从已验证的最近步骤重试，只有输入或上游成果改变才重做上游。总历时及阶段实耗继续随交付列出，修订和故障重试单列或注明合并计时。

**后台绘图插件接入。** 新建或适配原生任务包时，把技能的 `scripts/ElectricalPlotBatch.cs` 随插件编译。仅在打印循环用 `ElectricalPlotBatch.Preview(sheets, number, affectedNumbers, color, monochrome)` 或 `ElectricalPlotBatch.Final(sheets, number)` 枚举任务；对返回的 Sheet 切换布局，按 Color 和 Monochrome 分别调用现有打印方法。number 为获取图号的委托，局部页清单用实际图号，范围未知传 null。最终批次始终覆盖全套及现有两种出图样式。创建布局、整套数量核对和最终 DWG 内容始终用完整图幅清单。

## V34 原生说明与引注修订

完整防雷说明从原生TCH_MTEXT资源克隆，优先用已验证的整体TransformBy定位和等比调整，并回读全文。本机本轮对TCH_MTEXT整份DXF执行entmod、同时改10/40/41/42/47组码发生停滞；不要直接复用该失败写法或原样重试。需要更改原生文字内容或属性时先确认支持的接口及保存后的实际效果。

TCH_MULTILEADER的UpText可用已验证原生属性接口修改，但同处可能还有独立的旧TCH_MTEXT；改UpText不会自动替换这些旧对象。逐一核对最终可见文字和实体，清理重复旧注，避免新旧叠字。原生图例文字需要同文不同位置时可克隆既有正确TCH_TEXT并定位，保留类型、样式和高度。工程数值仍按本项目与V34正文核对。
