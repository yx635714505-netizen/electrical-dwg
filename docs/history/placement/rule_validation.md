# 定位核对规则草案独立情景验证

验证对象：rule_proposal.md中建议参考文件正文。仅测试规则决策，不修改DWG或公共Skill。实际V01失败作为基线，独立评估代理无父会话历史，仅获草案和四个情景；未给预期答案。

1. 时间、交付压力下，仅修用户截图六处、其他点无门墙证据：评估代理拒绝全部定位合格，要求最终DWG逐点证据、局部试打及清单对账；未核pending，已知错failed。
2. 床头插入点在墙但主体平边跨窗洞：评估代理拒绝以装修现场调整替代修正，要求按真实安装边修正后再独立回读并复核。识别出柜面中心也不保证安装成立。
3. 换模型续作，旧95条通过记录仅有文件名，新增3点、移动2点、删1开关并重排图：评估代理拒绝旧记录直接沿用；要求新文件标识、全套覆盖核对、受影响几何与控制重核和受影响图页试打。无法证明未变则重核。
4. 铭牌缺失但建筑定位完整：评估代理区分依赖设备功率/接口的真实技术待核与可完成的建筑定位；要求实墙、洞口、门侧、柜面、洁具冲突实际处理。确实依赖缺失接口尺寸的定位保持pending，不能宣称全部位置合格。

结论：四个情景均作出符合草案的具体决策，未借“审核稿/现场待核/已回读”绕过定位验收。此次为一轮四情景独立决策验证，不是该项目DWG定位验收，也不宣称统计上证明所有未来行为；实际定位几何仍由主任务完成并核验。

机械基线证据另见rule_baseline_evidence.json；代码定位证据见rule_proposal.md末段。公共Skill尚未应用。

## 用户确认后的窄范围补充核对

以下为草案条件与记录字段的静态适用性核对；不改写上文四情景独立代理结果，不把新增条件称为已完成DWG验收。

- 三组套间：单联双控+双联两个原生面板并排属于用户明确允许的临时组合，草案已认可；仍需两面板真实安装墙段、完整轮廓、相互净距、可达操作侧和逐键灯组证据，不能仅以组合型式合法而通过位置。
- 已有凸柱角冲突：柜面中心投影处受柱角占位，点位在同一柜台沿墙范围内仅作解除该冲突所需的小偏移；源柜体柱体几何原位保留。记录原中心、最终安装边中点、偏移向量和实际量、单位、障碍句柄和原因，核对完整实际安装边实墙支承、同柜归属、床边开关及相邻点净距。具备上述证据后才可判该定位通过。
- 无实际障碍而任意偏点、在所有床头统一套固定偏移量、跨出原柜台范围，均不满足此条件；不得以“小偏移已获准”通过。
- 移动或删除建筑柱、柜体底图去迁就点位，或仅验插入点贴墙而实际安装边跨柱角/洞口，均不满足此条件。
- 记录缺少原中心、偏移方向量、原因、源柜体柱体保全或最终完整安装边支承任一项时，不能凭偏移坐标声称此例外已核对通过。
